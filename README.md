# 단골 마케팅 스튜디오 (dangoal marketing studio)

단골(dangoal)의 주력 상품 **단골 스탬프 챌린지**를 알리고 판매하기 위한 **비용 0원 마케팅 자동화 웹앱**입니다.
서버·데이터베이스·외부 API·LLM 토큰을 전혀 쓰지 않고, HTML + CSS + Vanilla JS만으로 브라우저에서 100% 동작합니다.

- 콜드메일 생성 + 발송 파이프라인
- 카드뉴스 5장(1080×1080) Canvas 제작
- 상세페이지 섹션 빌더 + 단독 배포용 HTML 생성
- SNS 채널별 주간 지표 트래킹 + 룰 기반 병목 진단
- 타겟별 **'3무 부담'** 전략 보드

---

## 1. 바로 실행하기

### 가장 간단한 방법
`index.html`을 브라우저로 열면 됩니다. (파일 더블클릭)
모든 기능이 동작하지만, 브라우저에 따라 `file://`에서 다운로드·클립보드가 제한될 수 있습니다.

### 로컬 서버 (권장)
```bash
cd dangoal-marketing-app
python3 -m http.server 8000
# http://localhost:8000 접속
```
Node가 있다면 `npx serve .` 도 됩니다.

## 4. 기능별 사용법

 상단 탭은 `전략 보드 · 콜드메일 · 카드뉴스 · 상세페이지 · 지표 진단` 순서입니다.

### 4-1. 전략 보드
- 타겟 3개(동네 매장 / 무인매장·프랜차이즈 / 행사·상인회)의 **'3무 부담'** 매트릭스
- 세그먼트 8개의 고민·한 줄 후킹
- 브랜드 톤 규칙, 가격 정책, 바로 쓰는 카피(복사 버튼)
- 각 타겟 카드의 **“이 타겟으로 콜드메일 쓰기”** → 콜드메일 탭으로 조건이 넘어갑니다.

### 4-2. 콜드메일
- 입력: 타겟, 세그먼트, 매장/행사명, 업종, 지역, 담당자, 이메일, 챌린지 아이디어, 톤, 앞세울 3무
- 톤 4종: `정중한 첫 연락 / 짧고 담백 / 숫자·사실 중심 / 가벼운 제안`
- 결과: **제목 후보 3개** + 본문. “다시 생성”을 누르면 같은 조건에서 다른 문장 버전이 나옵니다.
- 버튼
  - **본문 복사** — 클립보드로 복사
  - **메일 앱 열기** — 본문을 클립보드에 복사한 뒤, 제목만 채운 메일 창을 엽니다. (본문은 메일 앱에서 붙여넣기)
  - **리드로 저장** — 아래 파이프라인에 저장
  - **다시 생성** — 문장 버전 변경
- 파이프라인: 상태 `초안 / 발송됨 / 회신옴 / 미팅확정`, 검색, 상태별 필터, 리드 CSV 내보내기
- 실제로 메일을 보낸 뒤 상태를 **발송됨**으로 바꿔 주세요. (앱이 자동으로 발송 여부를 알 수는 없습니다.)

### 4-3. 카드뉴스
- 5장 구성: `표지 → 문제제기 → 3무 해결책 → 작동방식 → CTA`
- 입력값을 고치면 미리보기가 즉시 갱신됩니다. (180ms 디바운스)
- 저장: **현재 슬라이드 PNG / 5장 개별 저장 / 전체 PNG(한 장, 1080×5400)**
- 브랜드 컬러: `#F6F2EB` `#D96B27` `#E07A38` `#1E1E1E`
- 폰트는 기기에 설치된 `Pretendard → Apple SD Gothic Neo → Noto Sans KR → 맑은 고딕` 순으로 사용합니다. 별도 웹폰트를 받지 않습니다.

### 4-4. 상세페이지
- 타겟·세그먼트·매장명·지역·챌린지 콘셉트·톤을 고르면 다음 섹션이 자동으로 만들어집니다.
  `히어로 → 숫자 → 문제 → 3무 → 작동 3단계 → 미션 예시 표 → 맞춤 견적 → FAQ → 최종 CTA → 푸터`
- **HTML 코드 복사 / HTML 저장** — 저장한 파일 하나로 그대로 배포할 수 있습니다.
- 결과물에는 외부 폰트·스크립트·이미지가 없습니다. (완전 단독 파일)
- 가격은 어떤 화면에도 고정 금액을 쓰지 않고 **“맞춤 견적 + 기본료 없이 쓴 만큼만 + 무료 프로모션”**으로 통일되어 있습니다.

### 4-5. 설정 (Settings)
상단 **설정** 버튼에서 두 가지를 관리합니다.

- **발신자 정보**: 담당자 이름·상호·연락처·이메일. 저장하면 콜드메일 서명, 상세페이지·카드뉴스 CTA, 전략 보드 연락처 카드에 반영됩니다. 값은 `localStorage`에만 저장되고 외부로 전송되지 않습니다. 비워 두면 서명·연락처 없이 생성됩니다.
- **잠금(로컬 암호화)**: PIN을 정하면 리드·지표·발신자 정보가 암호화되어 저장됩니다. PIN 변경·해제·지금 잠그기가 있습니다.
- **데이터**: JSON 내보내기/가져오기 (평문 백업 주의)

### 4-6. 지표 진단
- 채널: 인스타그램 / 블로그 / 콜드메일 / 기타
- 주간 입력: 주 시작일(월요일 권장), 노출, 클릭, 문의, 전환, 메모
- 같은 주·채널을 다시 저장하면 기존 행을 업데이트합니다.
- 시각화: 유입 퍼널, 채널별 문의·전환, 주간 추이 (SVG, 라이브러리 없음)
- 진단: 클릭률 1.5% / 문의율 8% / 전환율 35% 기준과 비교해 **가장 약한 단계**를 병목으로 지목하고 다음 액션 3개를 제안합니다.
- CSV 내보내기/가져오기, 예시 데이터 채우기
- 지표 정의
  - 노출: 콘텐츠 발행·도달 수 (콜드메일은 발송 수)
  - 클릭: 링크 클릭·프로필 방문·답장 열람 등 반응
  - 문의: DM·답장·전화·신청서 도착
  - 전환: 미팅 확정 또는 계약

## 5. '3무 부담' 설계

포스터의 “단골 스탬프 챌린지 '3무' 부담”에서 세 가지는 사이트·안내물 어디에도 정의돼 있지 않습니다.
이 앱은 **시작할 때 부담하지 않아도 되는 세 축**으로 정의하고, 타겟에 맞춰 언어를 바꿉니다.

| 축 | 동네 매장 | 무인매장·프랜차이즈 | 행사·상인회 |
|---|---|---|---|
| 비용 | 무(無)초기비용 — 초기 구축비·고정비 부담 無 | (2번에 통합) | (1건 단위 견적으로 대응) |
| 설치·기기 | 무(無)기기 — POS 연동·별도 기기·앱 설치 부담 無 | 무(無)연동 — POS·키오스크 교체·기기 설치 부담 無 | 무(無)설치 — 부스별 폼·QR 제작 부담 無 |
| 운영·집계 | 무(無)운영 인력 — 수기 집계·운영 인력 부담 無 | 무(無)응대 / 무(無)취합 — 직원 응대·지점 취합 부담 無 | 무(無)수기 / 무(無)동의 리스크 — 취합·개인정보 부담 無 |

타겟별 우선순위
- **동네 매장**: 초기비용 → 기기 → 운영 인력 (사장님 1인이 혼자 운영)
- **무인매장·프랜차이즈**: 직원 응대 → POS·키오스크 → 지점 취합 (사람이 없는 운영, 본사 보고)
- **행사·상인회**: 부스 설치 → 수기 취합 → 개인정보 동의 (당일 운영과 보고)

## 6. 데이터·백업

- 모든 리드·지표·발신자 정보는 브라우저 `localStorage`에 저장됩니다.
  - 잠금 꺼짐: `dangoal.mkt.v2` (평문)
  - 잠금 켜짐: `dangoal.mkt.v2.enc` (AES-GCM 암호문만 저장, 평문 키 제거)
- 상단 **내보내기** → JSON 파일 저장, **가져오기** → JSON 복원 (가져온 값은 살균 후 저장)
- 리드는 콜드메일 탭에서 CSV로도 내보낼 수 있습니다.
- 브라우저 데이터를 지우면 앱 데이터도 사라집니다. 중요한 리드는 JSON으로 백업하세요.
- 기기·브라우저마다 저장소가 따로입니다. 같은 데이터를 쓰려면 JSON을 옮겨 가져오세요.
- 시크릿(비공개) 모드에서는 저장이 되지 않을 수 있습니다.

## 7. 유지보수 가이드

### 문구·타겟 수정
`js/data.js` 한 파일에서 대부분 해결됩니다.
- `BRAND` — 이름, 연락처, 통계, 가격 정책, 톤 규칙, 카피 라이브러리
- `TARGETS` — 타겟 3개와 각각의 `hooks`(3무), `segments`, 메일 오프닝, 제목 템플릿
- `MU_AXES` — 3무의 공통 축
- `CHALLENGE_CONCEPTS` — 상세페이지의 챌린지 콘셉트와 미션 예시
- `CHANNELS` — 지표 채널

### 진단 기준 바꾸기
`js/metrics.js` 상단의 `BENCH` 값을 조정합니다.
```js
var BENCH = { ctr: 0.015, inquiryRate: 0.08, closeRate: 0.35, exposure: 1000 };
```

### 가격 정책
`BRAND.price`의 문구만 바꾸면 콜드메일·상세페이지·카드뉴스 CTA에 모두 반영됩니다.
현재는 **고정 금액 없이 맞춤 견적**이며, “기본료 없이 쓴 만큼만”과 “지금은 무료 프로모션”을 함께 안내합니다.
가격을 확정하기 전까지는 이 앱에서 금액을 노출하지 않습니다. 금액을 안내하기로 하면 `BRAND.price`에 문구를 추가하고 세 생성기의 가격 문구를 함께 바꾸세요.

### 새 타겟·세그먼트 추가
1. `TARGETS`에 타겟 객체를 추가하고 `hooks` 3개와 `segments`를 채웁니다.
2. 콜드메일/카드뉴스/상세페이지의 `<select>`에 `<option value="...">`를 추가합니다. (index.html)
3. 전략 보드와 매트릭스는 자동으로 반영됩니다.

### 새 챌린지 콘셉트
`CHALLENGE_CONCEPTS`에 `{id, label, headline, tagline, missions:[{name, rule, stamp}]}`를 추가하면
상세페이지 콘셉트 선택지에 자동으로 나타납니다.

### 문구가 어색할 때
콜드메일은 `js/coldmail.js`의 `problemBlock`, `proposalBlock`, `ctaBlock`, `muLines`를 봅니다.
타겟별 오프닝은 `data.js`의 `mailOpeners`, 제목은 `subjectLines`입니다.
`{name}`, `{industry}`, `{region}` 치환을 지원합니다.

## 8. 현재 버전의 한계

- **콜드메일 발송은 자동이 아닙니다.** `mailto:`는 메일 앱을 열 뿐이며, 실제 발송 여부는 사용자가 확인해야 합니다. (브라우저만으로는 발송 결과를 알 수 없습니다.)
- 메일 본문은 길이 제한 때문에 `mailto:`에 넣지 않고 클립보드로 복사합니다. (메일 앱에서 붙여넣기)
- 여러 장 다운로드를 브라우저가 차단할 수 있습니다. “5장 개별 저장”이 안 되면 슬라이드를 하나씩 저장하세요.
- 계정·동기화가 없습니다. 데이터는 브라우저에만 있습니다.
- 카드뉴스는 폰트를 웹폰트로 받지 않아, 기기에 Pretendard가 없으면 시스템 고딕으로 렌더링됩니다.
- 생성 문구는 규칙 기반입니다. LLM처럼 매번 새 문장을 쓰지는 않지만, 조건·톤·버전에 따라 조합이 달라집니다.

## 9. 보안·개인정보

이 앱은 공개 저장소에 올라가므로 **코드에 개인정보를 두지 않는 것**을 기본 원칙으로 합니다.

### 9-1. 코드에 없는 것
- 발신자 전화번호·이메일·이름은 `js/data.js`에 하드코딩되어 있지 않습니다.
- 실제 고객 리드·지표는 저장소에 포함되지 않습니다. 예시 지표는 명시적으로 “예시”로 표시됩니다.
- 연락처는 **설정(Settings)에서 입력**하며, 브라우저 `localStorage`에만 저장됩니다. 외부 전송은 없습니다.

### 9-2. 잠금(로컬 암호화)
- 설정 → “잠금 켜기”에서 PIN(4자리 이상)을 정하면, 리드·지표·발신자 정보 전체가 **AES-GCM 256**으로 암호화되어 `dangoal.mkt.v2.enc`에 저장됩니다.
- 키는 **PBKDF2-SHA256(250,000회)** 으로 PIN에서 유도합니다. PIN 자체는 저장하지 않습니다.
- PIN을 모르면 데이터를 열 수 없습니다. **PIN 분실 시 복구 방법은 없고, 초기화만 가능합니다.**
- “지금 잠그기”를 누르면 메모리에서도 데이터를 비우고 잠금 화면으로 돌아갑니다.
- 암호화를 끄면 다시 평문 저장으로 전환됩니다. (설정에서 현재 PIN 확인 후 가능)
- Web Crypto는 HTTPS 또는 localhost에서만 동작합니다. GitHub Pages는 HTTPS이므로 문제없습니다.

### 9-3. 수집 차단
- `robots.txt`: 모든 검색엔진과 주요 AI 크롤러(GPTBot, ChatGPT-User, CCBot, ClaudeBot, Anthropic-AI, Google-Extended, Bytespider, Applebot-Extended, PerplexityBot, meta-externalagent 등)를 `Disallow: /`로 차단
- `index.html`: `<meta name="robots" content="noindex, nofollow, noarchive, noai, noimageai">`
- `Content-Security-Policy`: `default-src 'self'` 기반. 외부 스크립트·프레임·폰트·연결을 차단하고 인라인 스크립트를 쓰지 않습니다.

### 9-4. 입력 처리
- 모든 동적 DOM 렌더링은 `Utils.escapeHtml` / `escapeAttr`를 거칩니다.
- JSON·CSV 가져오기는 값을 신뢰하지 않고, 문자열 길이 제한·숫자 변환·허용된 ID 목록 검사·제어문자 제거 후 저장합니다.
- 가져온 리드의 `id`는 새로 발급해 HTML 속성 주입을 막습니다.
- `mailto:`의 이메일은 `encodeURIComponent`로 처리합니다.

### 9-5. 한계 (반드시 함께 보세요)
- **저장소가 Public이면 소스코드는 누구나 볼 수 있습니다.** 그래서 민감정보를 코드에 넣지 않고 브라우저 로컬 암호화로 분리했습니다. 소스에 비밀을 두는 방식은 Public 저장소에서 성립하지 않습니다.
- `robots.txt`와 `meta robots`는 **수집 예절**을 요청할 뿐, 접근을 기술적으로 막는 장치는 아닙니다. 크롤러가 무시할 수 있습니다.
- 정적 사이트에는 로그인 게이트가 없습니다. 링크를 아는 사람은 페이지 자체를 열 수 있습니다. (데이터는 각자의 브라우저에만 있어 서로 보이지 않습니다.)
- 페이지 자체를 특정인만 보게 하려면 **Cloudflare Access(무료 50석)**, Vercel Password Protection(유료), Netlify Identity 같은 게이트를 앞에 두세요.
- `meta` CSP는 응답 헤더만큼 강력하지 않습니다. Cloudflare Pages를 쓴다면 `_headers` 파일로 같은 정책을 헤더로 내려주는 편이 좋습니다.
- PIN을 잊으면 데이터 복구가 불가능합니다. 중요한 리드는 JSON으로 백업하되, **백업 파일은 평문**이므로 공개 저장소·클라우드 공유 링크에 두지 마세요.
- XSS는 출력 이스케이프로 막았지만, 브라우저 확장 프로그램·악성 입력 등 로컬 환경의 위협까지 막지는 못합니다.
